Graphics, Files & Compression

Vector vs bitmap, lossless vs lossy compression, all image file formats, colour depth, resolution, and image enhancement metalanguage.

Core concepts

Vector Graphics

DefinitionImages defined by mathematical equations (paths, anchor points, curves, fills) rather than pixels
ScalabilityCan be scaled to any size with no quality loss — equations are recalculated at each size
File sizeRemains small regardless of scale — only stores mathematical data, not pixel grids
FormatsSVG, AI (Adobe Illustrator), EPS, PDF (can contain vectors)
Best forLogos, icons, illustrations, typography, print materials requiring multiple sizes
SoftwareAdobe Illustrator, Inkscape, CorelDRAW, Affinity Designer

Bitmap / Raster Graphics

DefinitionImages stored as a grid of individual pixels, each with its own colour value
PixelationWhen enlarged, individual pixels become visible — image appears blocky or blurry
File size= Width × Height × Colour depth (in bits) ÷ 8 = bytes
FormatsJPEG, PNG, GIF, TIFF, BMP, RAW
Best forPhotographs, complex images with subtle colour gradients
SoftwareAdobe Photoshop, GIMP, Affinity Photo, PaintShop Pro
Compression — expanded

🟢 Lossless Compression

DefinitionCompression that preserves ALL original data — file can be perfectly reconstructed
How it worksIdentifies patterns and replaces with shorter codes (Run-Length Encoding: "AAAAAA" → "6A"). No data is thrown away.
File size reductionModerate — typically 30–60% smaller than uncompressed
QualityIdentical to original — zero quality loss at any number of saves
Image formatsPNG, GIF, TIFF, BMP (optional)
Use whenLogos, screenshots, text-heavy graphics, images that will be edited further, archiving masters

🔴 Lossy Compression

DefinitionCompression that permanently discards data the human eye is least likely to notice
How JPEG worksDivides image into 8×8 pixel blocks, applies Discrete Cosine Transform, discards high-frequency detail (fine texture). Quality setting (1–100) controls how much data is removed.
File size reductionDramatic — can be 10× or more smaller than uncompressed
QualityDegrades with compression. Each resave as JPEG loses MORE data — called generation loss
ArtefactsBlocky areas, colour banding, blur — visible at high compression settings
Use whenPhotographs for web/email where file size matters more than perfect quality

Key metalanguage

Resolution & Colour Depth

ResolutionNumber of pixels per inch. Screen: 72–96 PPI. Print: 300+ DPI. Higher = sharper detail.
Colour depthBits per pixel. 1-bit=2 colours | 8-bit=256 | 16-bit=65,536 | 24-bit=16.7M | 32-bit=24-bit + alpha
True Colour24-bit colour depth — 16.7 million colours, the maximum visible to the human eye
File size (bytes) = Width × Height × (Colour depth ÷ 8)
Worked example

1920 × 1080 pixels @ 32-bit: 1920 × 1080 × 4 bytes = 8,294,400 bytes ≈ 7.9 MB uncompressed

Image Enhancement Terms

Anti-aliasingSmoothing jagged pixel edges by blending transitional pixel colours at boundaries — makes curves and text appear smooth
LayersIndependent stacked elements — each layer editable separately without affecting others. Non-destructive editing.
FiltersEffects applied to alter appearance: blur, sharpen, emboss, noise, distort
Colour balanceAdjusting ratio of RGB channels to correct or stylise the overall tone of an image
Brightness/ContrastBrightness = overall lightness. Contrast = difference between lightest and darkest areas.
Stroke & FillStroke = outline/border of a shape. Fill = interior colour or pattern of a shape.

Identify ONE file format that would be appropriate for saving a company logo that requires a transparent background for use on a website.

Answer: PNG (Portable Network Graphics)

PNG supports alpha channel transparency, allowing the background to be fully or partially transparent, which is essential for logos placed over coloured or patterned website backgrounds. SVG would also be accepted.

Short Answer3 marks
Describe the differences between vector and bitmapped images, with reference to how each handles scaling.
PEEL Format
P
Bitmapped images are made up of a fixed grid of pixels, while vector images are defined by mathematical equations (paths, anchor points and curves). 1 markPoint: defines both types accurately
E
When a bitmapped image is enlarged, the fixed pixel grid is stretched — individual pixels become visible and the image appears pixelated or blurry. In contrast, vector images are recalculated mathematically at every new size, so they remain perfectly sharp and smooth at any scale. 1 markEvidence: explains the scaling behaviour of both types
L
This is why vector formats such as SVG or AI are preferred for logos and graphics that must appear at multiple sizes, whereas bitmap formats like JPEG and PNG are suited to photographs where subtle colour gradients are more important than scalability. 1 markLink: applies distinction to practical context
Short Answer3 marks
Calculate the uncompressed file size in MB of an image that is 1920 × 1080 pixels with a colour depth of 32 bits. Show all working.
Step 1: Total pixels = 1920 × 1080 = 2,073,600 pixels
Step 2: Bits = 2,073,600 × 32 = 66,355,200 bits
Step 3: Bytes = 66,355,200 ÷ 8 = 8,294,400 bytes
Step 4: MB = 8,294,400 ÷ (1024 × 1024) = 7.91 MB
Mark breakdown

Mark 1: correct pixel multiplication. Mark 2: correct application of bit depth and conversion to bytes. Mark 3: correct final MB answer with working shown.

Extended Response4 marks
Compare lossless and lossy compression methods, explaining how each affects image quality and data storage requirements.
PEEL Format
P
Lossless compression retains all original image data, while lossy compression permanently removes data that the human eye is least likely to notice — typically fine texture and high-frequency detail. 1 mark
E
In lossless compression (used in PNG and GIF), repeated patterns are replaced with shorter codes. This means the image can be perfectly reconstructed — quality is identical to the original at any number of saves. However, the reduction in file size is moderate, typically 30–60%. 1 mark
E
Lossy compression (used in JPEG) achieves far greater file size reductions — sometimes 90% or more — by permanently discarding pixel data. This causes visible artefacts such as blockiness at high compression, and quality degrades further each time the file is saved. 1 mark
L
The choice therefore depends on the intended use: lossless is preferred for logos, screenshots and any image requiring further editing, while lossy is appropriate for photographs distributed online where minimising file size is more important than perfect quality. 1 mark

Describe the ethical implications of image manipulation and enhancement in the multimedia industry, using examples.
STEEL Format
S
Image manipulation and enhancement in the multimedia industry raises significant ethical concerns relating to authenticity, misinformation, and harm to individuals. 1 mark
T
Over-editing photographs in advertising — for example, digitally slimming models or removing blemishes to create an unrealistic ideal — can have harmful psychological impacts on audiences, particularly young people, by establishing unattainable beauty standards. 1 mark
E
In journalism, altered images can mislead the public and distort facts. For instance, a news photograph digitally altered to change a crowd size or show a politician in a false context constitutes misinformation and erodes public trust in media. 1 mark
E
Conversely, image manipulation can also serve ethical purposes — pixelating or blurring the faces of victims in news footage protects the privacy and dignity of individuals in traumatic situations. 1 mark
L
Copyright and ownership issues also arise when images are modified without proper attribution or consent, violating the intellectual property rights of the original creator. Ethical practice in multimedia therefore requires transparency, consent, and a careful balance between creative expression and honest representation of reality. 1 mark

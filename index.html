Essential Formulas

File Size (Images)

Width × Height × Bit Depth ÷ 8 ÷ 1024 ÷ 1024 = MB

Example: 1920 × 1080 × 32 ÷ 8 ÷ 1024 ÷ 1024 = 7.91 MB

Transfer Time

File Size (MB) × 8 ÷ Speed (Mbps) = Seconds

Example: 550 MB × 8 ÷ 80 Mbps = 55 seconds

Storage Capacity

Total Storage ÷ File Size = Number of Files

Example: 650 MB ÷ 5.26 MB = 123 pages

Project Costing

Units × Cost per Unit + Design Fees = Total

Example: 800 × $0.85 + $60 = $740
